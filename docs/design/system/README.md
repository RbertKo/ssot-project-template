# Design System

승인된 디자인 시스템 릴리스를 관리한다. Claude Design의 팀 디자인 시스템은 작업 공간이고, 이 문서의 릴리스 표는 제품이 사용할 기준선을 고정한다.

## Release Rules

- 버전은 `vMAJOR.MINOR.PATCH` 형식을 사용한다.
- 토큰 의미 변경이나 호환되지 않는 컴포넌트 변경은 `MAJOR`를 올린다.
- 하위 호환 컴포넌트 추가는 `MINOR`를 올린다.
- 시각적 수정이나 문서 보완은 `PATCH`를 올린다.
- 각 릴리스는 Claude Design 소스와 승인 시점의 내보내기본을 연결한다.
- 과거 릴리스를 삭제하지 않는다.

## Minimum Contents

디자인 시스템 릴리스에는 최소한 다음 항목을 포함한다.

| 영역 | 내용 |
| --- | --- |
| Foundations | 색상, 타이포그래피, 간격, 반경, 그림자 |
| Components | 컴포넌트 목록, 상태, 변형 |
| Patterns | 폼, 피드백, 내비게이션, 빈 상태 |
| Accessibility | 대비, 키보드, 포커스, 모션 기준 |
| Change Log | 변경 내용, 이유, 영향 |
