# API Contracts

표는 원문 메타데이터의 파생 뷰다. 원문을 수정한 뒤 저장소 루트에서 `node scripts/ssot-docs.mjs --write`로 갱신한다. 생성 구역을 직접 편집하지 않는다.

API 계약과 버전의 원본을 관리한다.

## Rules

- 파일명은 `API-NNN-slug.md` 형식을 사용한다.
- 각 문서는 현재 버전, 과거 버전, 변경 이유, 호환성 영향을 기록한다.
- 제품 요구사항은 복제하지 않고 관련 `PRD-*`를 참조한다.
- 구조 결정이 필요한 변경은 관련 `ADR-*`를 참조한다.
- 호환되지 않는 변경은 명시적으로 새 메이저 버전으로 기록한다.

새 계약은 [`API-000-template.md`](API-000-template.md)를 복제해 작성한다.
