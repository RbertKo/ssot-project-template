# 구현 기록

구현 과정·핸드오프·검토 근거를 보존한다. 실제 동작은 코드와 테스트, 요구사항·완료 판정은 연결 PRD가 소유한다.

새 기록에 포함할 항목: 연결 PRD·WORK·변경 경로·커밋 또는 PR·구현 판단·검증 근거.

당시 관측과 현재 계약을 구분한다. 이곳에 별도 백로그나 중복 상태 표를 만들지 않는다.

정본 탐색: [PRD 인덱스](../product/prd/README.md), [SSoT 규칙](../governance/ssot.md).
