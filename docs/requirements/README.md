# 요구사항 수집·정제

사용자 요청·인터뷰·초안의 맥락을 보존한다. 현재 상세 요구사항·완료 기준·작업 상태는 연결 PRD가 소유한다.

새 기록에 포함할 항목: 출처·수집 시점·문제와 가설·미확정 질문·승격한 PRD 링크.

승격 전 기록을 승인된 스펙으로 서술하지 않는다. 승격 후에는 내용을 복제하지 않고 정본 PRD를 가리킨다.

정본 탐색: [PRD 인덱스](../product/prd/README.md), [SSoT 규칙](../governance/ssot.md).
