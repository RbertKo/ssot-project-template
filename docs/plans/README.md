# 실행 계획

PRD를 실현할 실행 방법·순서·의존성 검토를 기록한다. 현재 작업 상태와 우선순위는 PRD Work Items를 따른다.

새 기록에 포함할 항목: 연결 PRD·WORK·접근 방법·결정 참조·검증 계획.

계획 변경이 요구사항·완료 기준에 영향을 주면 해당 PRD를 먼저 갱신한다.

정본 탐색: [PRD 인덱스](../product/prd/README.md), [SSoT 규칙](../governance/ssot.md).
