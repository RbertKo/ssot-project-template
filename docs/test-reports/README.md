# 검증 결과

검증 시점의 실행 결과와 한계를 보존한다. 과거 통과 기록만으로 현재 브랜치의 검증이나 PRD 완료를 선언하지 않는다.

새 기록에 포함할 항목: 연결 PRD·WORK·대상 커밋·환경·실행 명령·기대/실제 결과·실패 또는 생략 이유.

실행하지 못한 검사를 통과로 기록하지 않는다. 시크릿 값을 남기지 않는다. 완료 근거는 해당 PRD의 Validation·Work Items에 연결한다.

정본 탐색: [PRD 인덱스](../product/prd/README.md), [SSoT 규칙](../governance/ssot.md).
